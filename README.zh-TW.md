# allosteric-benchmark

[English](README.md) · **繁體中文**

量子漫步在相同輸入下,能不能比古典方法更準地預測異位位點?這個 repo 就是為了回答這個
問題而建的。在**幾何代理標籤**的 benchmark 上,七個插入點一致給出否定答案——然後用
**策展**異位標註做的檢驗(第 10 節)推翻了其中幾個排名,包括那一個。這裡提供 benchmark、
對照組、策展交叉檢驗,以及背後全部的程式碼。

> **請先讀第 10 節。** 策展標籤的檢驗推翻了本 repo 先前領銜的三個主張,包括
> 「ALPS 是最好的方法」與「CTQW baseline 表現等同亂數」。兩者都是代理標籤的性質。

所有東西都從同一組極簡輸入出發:**每殘基的 Cβ 座標,加上活性位點殘基索引**,沒有別的。
不用分子動力學軌跡、不用結合態(holo)參考結構、推論時不用任何學到的權重。
用 `numpy` + `scipy` 即可從公開資料重現。

**三項交付:**

1. **一個帶平庸對照的 benchmark。** 直接從 RCSB PDB 建立、family-declustered 的目標集,
   因為這領域的標準 benchmark 伺服器(ASD、ASBench、CASBench)目前全部無法連線。
   每個結果都與「只用距離」「只用埋藏度」「亂數」三個對照並列報告——因為在這個任務上
   那些對照很強,而好幾個已發表方法的移植版**贏不過它們**。
2. **一份對量子漫步的系統性陰性結果**,機制是量出來的而非斷言的,並且原地記錄了
   小樣本結論在大樣本上沒有存活的自我更正。
3. **ALPS**,從比較中產出的古典方法:局部擾動接觸圖、讀最低三個 Kirchhoff 本徵值的位移、
   對距離做 z-score。每個設計決策都可追溯到第 4 節的某次量測——而第 10 節顯示
   **最後那個決策是對著一個假象調出來的**。

> **關於量子框架。** ALPS 讀的 Kirchhoff 矩陣**就是**連續時間量子漫步的 Hamiltonian,
> 所以「配體結合如何重新調諧漫步的低階頻譜」是個公道的描述。但它同樣是 Gaussian Network
> Model 最慢振動模態的描述——**同一組數字**。**本 repo 不在任何地方宣稱量子優勢**,
> 第 6 節記錄了七次尋找它而失敗的嘗試。

## 摘要

**對照組告訴我們什麼。** 在 101 個獨立目標上,一個只用距離的對照
(`分數 = 距活性位點的距離`)達到 46–55% 的置換顯著率,以及全場最高的 AUC。
**贏不過那個對照的方法,什麼都沒有證明**——而這裡多數已發表方法的移植版都贏不過。

**ALPS 在代理標籤上做到什麼。** 定位領先:top-5 命中率 24.4%,對比距離對照的 7.8%;
加上空間分散後到 35.6%。

**策展檢驗說了什麼。** 在 73 個有專家標註的目標上,ALPS 的 AUC **在十二個方法中排第六**
(0.577)。bond-to-bond 未做距離校正版領先(0.618),而本 repo 要檢驗的 CTQW baseline
達 0.590——高於亂數對照,**也高於 ALPS**。ALPS 的距離 z-score(設計上最推崇的組件)
在真標籤下**反而降低**準確度(有 0.577 vs 無 0.598),因為它校正的偏差只存在於我們自己
的標籤建構裡。**沒有任何方法在超過 1.9% 的目標上達到 DCC ≤ 4 Å。**

**量子漫步的下場。** 九個逐殘基插入點全部在策展標籤與無混淆指標上測過,
沒有一個與亂數對照可區分;兩個解析上關閉(單粒子模型下 OTOC 與 Lieb-Robinson
**等於**已否決的傳輸振幅);一個結構上排除(非厄米感測需要接觸圖沒有的結構);
一個依文獻排除(量子核);一個明確未評(量子儲備計算)。

**該不信什麼。** 主 benchmark 的標籤是幾何代理,而第 10 節顯示這比任何其他但書都重要:
在策展標註下方法排序重排、ALPS 掉到第六、CTQW baseline 升到它之上,而且塑造了數個設計
決策的**距離偏差原來是我們自己標籤建構的產物**(`ctrl_dist` 從最強變成 AUC 0.383,
低於隨機)。本文件有四個結論在樣本或標籤改變時反轉(第 7、9、10 節與學習型組合器的揭露),
**每一個舊讀數都保留而非刪除**。

## 1. 任務、資料與方法

在進入發現之前的定位說明。第 2 節之後都預設你讀過這裡。

### 1.1 任務

**每個方法的輸入:** 單一結構的 `(N, 3)` 每殘基 Cβ 座標,加上活性位點殘基的整數索引。
沒有別的——不用序列、不用 MD 軌跡、不用結合態參考結構、不用學到的權重。

**輸出:** `(N,)` 每殘基分數,越高表示越可能屬於異位位點。由此在**候選池**
(距每個 anchor 殘基至少 8 Å、且自身非 anchor 的殘基)中取分數前五名作為預測。

**評估分兩個層級**,回答不同的問題:

| 層級 | 問題 | 做法 |
|---|---|---|
| 殘基 | 在已知有位點的蛋白質內,該位點能否被排在前面? | **距離分層 AUC**——只比較彼此距活性位點差距 ≤2 Å 的正負例配對,使近度無法灌水(§10.4) |
| 蛋白質 | 這個蛋白質到底有沒有異位位點? | 對蛋白質層級負例的每蛋白統計量——**目前無解**,見第 11 節 |

原始 AUC、置換顯著率與 top-5 命中率也有報告,但 §10.3 顯示原始 AUC 在兩種標籤下都被
近度主導,所以那是脈絡而非結果。

### 1.2 資料格式

每個目標集都是一個目錄,一個蛋白質一個 `.npz`,schema 一致:

| 欄位 | 形狀 | 意義 |
|---|---|---|
| `cb` | `(N, 3)` float | 每殘基 Cβ 座標(Å);甘胺酸與 Cβ 未解析處以 Cα 代替 |
| `anchor` | `(A,)` int | 活性位點殘基在 `cb` 中的 0-based 索引 |
| `y` | `(N,)` int | 異位位點殘基為 1,其餘為 0;負例集全為 0 |
| `resnums` | `(N,)` int | 作者殘基編號,用於把預測映射回 PDB |
| `chain_id` | `(N,)` str | 每殘基所屬鏈——策展集、多聚體集、配對集才有 |

`y` **僅供評估**,沒有任何方法讀取它。載入只要兩行:

```python
d = np.load("data/targets_curated/4HO6.npz")
scores = alps_scores(d["cb"], d["anchor"])          # 方法只看到這兩個陣列
top5   = d["resnums"][alps_select(d["cb"], d["anchor"])]
```

### 1.3 八個目標集

三種標註規則。**數字出自哪一集會改變它的意義**,而那正是第 10 節的主題。

| 目標集 | n | 標註 | 為何而建 |
|---|---|---|---|
| `targets_curated/` | 97 | **專家策展**的異位與活性位點殘基(ASBench/ASD,經 ALLO 論文補充資料) | 頭條結果——唯一不是我們自製的標籤 |
| `targets/`(tier-A) | 11 | 幾何代理,取自 RCSB 全文含 *allosteric* 的條目 | 早期調參;已被取代 |
| `targets_b/`(tier-B) | 90 | 幾何代理,一般查詢 | 原始留出集;**已證實受混淆,見 §10.2** |
| `targets_multimer/` | 88 | 幾何代理,整個組裝體當一張圖 | 對稱寡聚體檢驗(第 9 節) |
| `targets_negative/` | 90 | **沒有異位位點**——有輔因子、無類藥物配體 | 蛋白質層級負例(第 11 節) |
| `matched_pos/` `matched_neg/` | 18 / 83 | 兩類走同一條 pipeline | 修正後的蛋白質層級檢驗(§11.2) |
| `qasc_targets/` | 3 | 受測方法自附 | 重現它已發表的結果 |

代理標籤的意思是「一個類藥物分子結晶於此,距催化位點 ≥ 8 Å」——這是該領域的操作型定義,
**不等於**實驗證實的異位位點。第 10 節量測了這個區別有多重要,答案是:非常重要。

### 1.4 方法一覽

全部在 [`methods/`](methods/),相同輸入簽章、相同後處理。

| | |
|---|---|
| **`ALPS`** | 加勁每個殘基的鄰域,讀最低三個 Kirchhoff 本徵值的位移,對距離做 z-score——**唯一越過雜訊地板的方法**(§10.6) |
| `apop` | 同樣的加勁,依全域模態頻率位移排名;**不使用 anchor** |
| `corrsite` | GNM 快/慢模態對 anchor 的運動相關性,取兩者 Z-score 最大值 |
| `prs` | 擾動響應掃描;GNM 共變異數矩陣**就是**線性響應算子 |
| `btb` / `btb_raw` | bond-to-bond propensity——加權 Laplacian 的 Green 函數,自 anchor 播種 |
| `qasc_baseline` | 受測的 CTQW 方法:無限時間相干傳輸 + IPR 共振轉移 |
| `ctqw_only` | 該方法的傳輸通道單獨使用 |
| `qfi` | 局部擾動的量子 Fisher 資訊,在活性位點讀取 |
| `enaqt`、`chiral`、`qpr`/`cpr` | 去相干輔助傳輸;手性(破壞時間反演)漫步;擾動框架下的相干核與古典核 |
| **對照組** | `ctrl_dist`、`ctrl_closeness`、`ctrl_burial`、`ctrl_random`——完全沒有模型。**每個結果都與它們並列報告**,因為在這個任務上它們很強,而好幾個方法移植版贏不過 |

## 2. 為何要自建 benchmark

這個任務的標準標註 benchmark 實際上已經離線:

| 資源 | 狀態(2026 年 8 月實測) |
|---|---|
| ASD (`mdl.shsmu.edu.cn/ASD/`) | HTTPS 無回應;下載連結為 JS 驅動,無法機器取得 |
| CASBench (`mdl.shsmu.edu.cn/CASBench/`) | HTTP 404 |
| `casbench.org` | 無法解析 |

所以 benchmark 從原始資料重建。位點定義沿用 ASBench 與 CASBench 的慣例
——以晶體複合物中直接接觸配體的殘基界定位點:

| 欄位 | 規則 |
|---|---|
| `anchor`(正位/活性位點) | 任一重原子距**輔因子**配體 ≤ **4.5 Å** 的殘基(核苷酸、NAD/FAD/SAM/CoA/PLP、血基質、糖磷酸) |
| `y`(異位位點) | 距**類藥物**配體 ≤ **4.5 Å** 的殘基:重原子 ≥ 12、含 N/S/鹵素(排除只有 C/O 的 PEG 與甘油)、非輔因子、非結晶添加物 |
| 保留條件 | 兩位點不重疊,且相距 **≥ 8 Å** |

兩層,皆以 PDBe SIFTS 的 UniProt accession 去重,確保沒有蛋白質家族出現兩次。

### ⚠️ 標籤是代理,不是專家策展

`y` 的意思是「**一個類藥物分子結晶在此,遠離催化位點**」。那是該領域的操作型定義、
也是 ASBench 式資料集所編碼的東西——但**不等於**實驗證實的異位調控位點。
本 benchmark 得出的每個結論都帶著這個但書。

## 10. 策展標籤,以及它們迫使的更正

英文版第 10 節。完整中文內容見 [`docs/RESULTS.zh.md` §3.9](docs/RESULTS.zh.md)。要點:

**全部 97 個策展目標中的 96 個可評估**,距離分層 AUC,對照地板 0.496 ± 0.016
(由 25 個獨立亂數對照估計):

| 方法 | 分層 AUC | 相對地板 | 配對 p |
|---|---|---|---|
| **`ALPS`** | **0.591** | **+0.094** | **0.0030** ✓ 通過 Bonferroni |
| `apop` | 0.533 | +0.036 | 0.60 |
| `ctqw_only` | 0.519 | +0.023 | 0.94 |
| 對照 `ctrl_random` | 0.519 | — | 基準 |
| `qasc_baseline` | 0.506 | +0.010 | 0.67 |
| `btb_raw` | 0.504 | +0.008 | 0.45 |
| 對照 `ctrl_closeness` | 0.473 | −0.024 | 0.0026 |
| `qfi` | 0.465 | −0.031 | 0.037 |

**ALPS 通過多重比較校正**(p = 0.0030,門檻 0.05/11 = 0.0045)。這是本 repo 中唯一
同時通過「更大樣本、策展標籤、無混淆指標、容忍窗掃描、多重比較校正」的主張。

**而且不是小結構效應**:依尺寸分層,margin 在整個範圍穩定(N≤520 為 +0.090、
521–900 為 +0.063、>900 為 +0.067)。

**沒有任何量子讀數與亂數對照可區分**,`qfi` 甚至顯著低於它。

## 11. 最重要的限制:沒有方法知道何時該說「沒有」

上面所有結果回答的都是**「已知有位點時,該位點能否被排前面」**。本 repo 每個目標
依建構規則都有已知位點,所以使用者最先面對的問題從未被問過:
**給一個沒有異位位點的蛋白質,方法會說沒有,還是照樣指出五個殘基?**

一個永遠回傳五個殘基的方法,在只有正例的 benchmark 上分數很好,
卻會把實驗團隊送去追不存在的位點。

### 11.1 對照組攔下了這個實驗,然後診斷變得更糟

`ctrl_dist`(只用距活性位點的距離)以 **0.752** 分離兩類,遠高於任何方法。
兩輪配對都沒能移除它:

| 配對方式 | 配對數 | `ctrl_dist` | `ALPS_raw` |
|---|---|---|---|
| 僅殘基數 | 1139 | 0.755 | 0.537 |
| 殘基數**與迴轉半徑** | 734 | **0.741** | 0.522 |

直接量還有什麼不同:

| 性質 | 正例 | 負例 | AUC |
|---|---|---|---|
| 活性位點偏離幾何中心(相對 Rg) | 0.581 | 0.486 | 0.641 |
| **活性位點佔全蛋白的比例** | **0.042** | **0.072** | **0.270** |

**兩組的 anchor 是用不同程序定義的。** 正例的活性位點來自策展表格(專家標註,緊緻);
負例的來自我們自己的幾何規則(距輔因子 4.5 Å 內),系統性地寬鬆 1.7 倍。
而本 repo **每個方法都從 anchor 播種**,所以每個分數都繼承了這個差異。

### 11.2 執行修正:診斷成立,但修正後的實驗檢定力不足

[`scripts/build_matched_sets.py`](scripts/build_matched_sets.py) 用**同一套程序**
重建兩類——全部鏈、anchor = 距輔因子 4.5 Å 內——只剩異位標籤不同。
(寫的過程中浮現第二個不一致:正例保留全部鏈、負例只取一條,這本身就解釋了
先前配對一直在對抗的尺寸落差。)

**診斷是對的**,三個量全部往預測方向移動:

| | 修正前 | 修正後 |
|---|---|---|
| 活性位點佔比 | AUC 0.270 | 0.386 |
| 殘基數 | 0.783 | 0.631 |
| **`ctrl_dist`(尺寸與形狀配對)** | **0.741** | **0.646** |

**但修正後的實驗同樣無法回答問題。** 要求結構中有輔因子(共用 anchor 規則的代價)
使正例只剩 **18 個**對 83 個負例,而在這個樣本量下雜訊地板升上來吃掉一切:
`ctrl_random` 落在 **0.563**,而 ALPS 在它**之下**(0.504)。

**這個問題現在停在哪:** 未解決,但理由變了——不是沒注意到的混淆,而是樣本小到看不穿。
真正要解決它,需要**活性位點策展標準與正例相同的負例**,而那又回到第 2 節描述的
同一個資料庫離線問題。

## 12. 限制(必須與結論一起引用)

1. **主 benchmark 的標籤是幾何代理**,不是實驗證實的異位位點。第 10 節用策展標註
   重跑全部評估並報告哪些結論存活;**有兩個沒有**。
2. **代理 benchmark 有策展標籤所沒有的距離偏差**(第 10 節)。代理標籤上
   `ctrl_dist` 達 42–55%;策展標籤上掉到 AUC 0.473,低於隨機。
   代理標籤的排名應視為在量測我們的建構,和量測任務一樣多。
3. **ALPS 超參數選自 tier-A**;tier-B 才是無偏估計。
4. **座標為 holo 構型**(移除配體後只用蛋白座標),嚴格說不是 apo。
5. `apop`、`qpr`、`cpr` 在 N > 660 的目標上跳過,故其 n 略少。
6. **小樣本會誤導,而且發生了不只一次。** 協同 QUBO 的命中率在 n=11 時 45.5%、
   n=89 時 23.6%(低於自己的亂數對照);對稱多聚體的結論在 n=4 與 n=29 之間反轉;
   學習型組合器的數字涵蓋 89 個合格目標中的 59 個。
   **本文件中任何來自小於約 30 個目標的數字,都應視為假說而非結論。**
7. **蛋白質層級的偽陽性率未知**(第 11 節),而那對實際使用是最重要的一項。

### 殘基圖 GNN(§1.5)

文獻調查(2,536 篇去重論文、27 張逐字驗證證據卡)問了兩個問題:哪些 AI 模型家族能做這個任務,
以及哪些能在**我們這組輸入**下跑。只有兩個存活:ALPS 已經是的彈性網路路線,以及**殘基圖 GNN**
——後者在整個語料庫裡沒有人在異位任務上做過殘基層級的刻畫。

| | 分層 AUC | GNN − ALPS | 配對 p |
|---|---|---|---|
| GNN,種子 0 | **0.622** | +0.030 | 0.136 |
| GNN,種子 1 | **0.630** | +0.038 | 0.151 |
| GNN + 距離通道 | 0.595 | +0.003 | 0.787 |
| ALPS | 0.592 | — | — |
| 對照 `ctrl_dist` | 0.509 | — | — |

這是這個 repo 目前最強的數字,兩顆種子都明確高於隨機對照,但**和 ALPS 分不開**:差距在兩組獨立
切分上都重現(所以不是切分的產物),但 n = 96 的配對檢定分不出兩者,兩次都是。

**值得留下的是消融結果。** 基礎模型被**刻意不給**「到活性位點的距離」這個通道——§10 證明過鄰近性
主宰 plain AUC,而學習型組合器拿到距離就會把它學回來。把這個通道給 GNN 之後,它**變差了**
(0.622 → 0.595),對 ALPS 的優勢也塌到零。不給混淆變數不但沒有代價,反而有幫助:拿到那個通道,
網路會把容量花在重現距離,而不是學圖上的傳遞。這是 §10 在學習型組合器上量到的同一個行為,現在在一個
完全不同的模型家族上重現——這讓它看起來是**任務的性質**,而不是某個架構的性質。

兩顆種子還說了一件關於對照組的事:`ctrl_random` 分別是 0.522 與 0.480,相差 0.042,夾住 25 顆種子
估出的地板 0.4963 ± 0.0157。而 `ctrl_dist` 是確定性的,兩次都是 0.509,但它對隨機對照的 p 值一次是
0.4120、一次是 0.0076——同一個數字、相反的結論,純粹因為比較對象移動了。這個 repo 裡任何以**單次**
隨機抽樣為對照算出的 p 值,都該帶著這個幅度來讀。

### 更大的資料集(§1.6)

樣本量是這個 benchmark 的綁定約束——文獻調查量到這個任務的標準訓練集是 90–235 個蛋白質,
我們的 curated set 是 97 個。因此把 [leo07010/allosteric-dataset-pipeline](https://github.com/leo07010/allosteric-dataset-pipeline)
(MIT,commit `4082cb1`)**整份搬進** [`external/allobench-pipeline/`](external/allobench-pipeline/),
而不是用引用的方式,讓這個 repo 能獨立運行。它建出 **1,439 個樣本、327 個獨立 UniProt、
1,367 個 PDB 結構**,而且**每個樣本都有活性位點標註**——這正是我們「給定活性位點、找異位位點」
的形式所必需的。

```bash
ALLOBENCH_CSV=/path/to/AlloBench.csv bash scripts/build_allobench.sh
python3 scripts/adapt_allobench.py --selftest   # 無授權資料也能驗證轉接器
```

**「獨立運行」指的是不依賴上游 repo,不是不需要外部資料。** AlloBench.csv 依其條款不可轉散布,
所以上游和我們都不附帶它,也不附帶任何由它衍生的殘基註釋。搬進來的是機器,不是資料集。

三個差異是**承重的**,轉接器不會把它們抹平:

| | curated(97) | AlloBench 路線(1,439) |
|---|---|---|
| 座標 | **Cβ** | **Cα** — ALPS 的 `RADIUS = 12.0` 是在 Cβ 上調的,套用前必須重調,而且要同時 held out 身分與大小(§10.5) |
| 標註 | 專家策展 | **距調節劑 4 Å 重原子** — §10 記錄了三個因標註構造改變而反轉的結論,所以兩個集合**分開評估,絕不合併** |
| 構象 | holo(§12.4) | holo |

最後一列是**不會改變**的那一個:兩邊都是調節劑已結合的結構,§12.4 早已揭露我們自己也是如此。
這次整合既沒有引入這個限制,也沒有修好它。
