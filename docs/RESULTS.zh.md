# 結果

> 本文件是 [README.zh-TW.md](../README.zh-TW.md) 的結果附冊 · [English README](../README.md)

> **本研究的最終定位**:這是一份**系統性的陰性結果研究**——量子漫步的七種插入方式全部
> 未能勝過古典讀數——外加一個帶平庸對照的公開 benchmark,以及一個從比較中產出的
> 古典方法(ALPS)。ALPS 唯一站得住的優勢是**定位**(top-5 命中率 24.4%,加空間分散
> 35.6%,對照距離基準的 7.8%);它在 AUC 上其實輸給「只算距離」的對照(0.603 vs 0.614),
> 顯著率的領先也落在信賴區間內。**所有方法在 DCC ≤ 4 Å 判準上皆為 0%。**
> 本 repo **不宣稱任何量子優勢**。
>
> **§3.9 用專家策展標註在全部 73 個目標上重跑,推翻了本文件三個主張**:
> ALPS 在 AUC 上僅排第六(0.577);bond-to-bond 未做距離校正版領先(0.618);
> **QASC 的 CTQW baseline 達 0.590,高於隨機對照也高於 ALPS**——「等同亂數」是代理標籤的性質。
> 且 ALPS 的距離 z-score 在真標籤下**反而有害**(0.577 有校正 vs 0.598 無校正)。

## 2. QASC 的診斷

### 2.1 它在自己的三個目標上是真的

`qasc_baseline` 在 QASC 自選目標上 100% 顯著、AUC 0.731,而**三個平庸對照全部失敗**
(距離 0%、亂數 0%、埋藏度 33%)。頭條結果不能用「其實只是距離或埋藏度」解釋,應予承認。

### 2.2 但在 68 個獨立目標上等同於亂數

tier-A 9.1%、**tier-B 7.8%,低於亂數對照的 8.9%**;AUC 一致低於 0.5
(0.412 / 0.416)——不是沒訊號,是**系統性把真異位殘基排在背景之下**。
top-5 命中率在 90 個留出目標上是 **4.4%**,亦低於亂數對照的 13.3%。

### 2.3 原因:分數本質上是「離活性位點的近度」

corr(QASC 分數, 距 anchor 距離)在三個集上分別是 **−0.713 / −0.621 / −0.604**
(此量與標註無關,純為 QASC 本身性質)。而它自選的三個目標恰好有個共同性質:
標註的異位殘基比 distal 背景**更靠近**活性位點(平均近 4.2 Å);獨立集上則偏遠
(+1.0 Å / +4.0 Å)。一個「近度排序器」在前者顯著、在後者反向失效,AUC<0.5 由此而來。

## 3. ALPS:本研究提出的新方法

定義與設計依據見 [`README.md`](README.md)。要點:局部加勁擾動 → 讀 Kirchhoff 矩陣
**最低 3 個非零本徵值的相對位移** → 對距離做條件 z-score。

### 3.1 留出集表現

在 90 個未參與調參的目標上:

- **AUC 0.603**,高於 APOP 的 0.564、QASC 的 0.416
- **top-5 命中率 24.4%**,約為距離對照(7.8%)的 **3.1 倍**、APOP(17.2%)的 1.4 倍,
  而 QASC 只有 4.4%
- 顯著率 48.9%,高於距離對照(45.6%),但略低於 APOP(50.6%)
- 強方法中中位 DCC 最短(20.2 Å vs APOP 26.4 Å)

**誠實的解讀**:ALPS 在顯著率上贏過距離對照的幅度很小(48.9% vs 45.6%),落在信賴區間內;
`apop` 的顯著率甚至略高(50.6%),但在 AUC、hit5、DCC 三項都輸。ALPS 真正站得住的優勢是
**定位**——top-5 命中率 24.4% vs 距離對照 7.8%,這個差距才明顯超出誤差範圍。
如果目標是「產出 5 個值得做實驗的候選殘基」,ALPS 是較好的選擇;
如果只問「這個蛋白質有沒有富集訊號」,兩者等價。

拿掉距離 z-score(`ALPS_noresid`)會損失顯著率(46.7%)與 AUC(0.584),但 hit5 不降
(25.6%),表示該校正銳化的是整體排序而非最頂端。

### 3.2 調參集到留出集的落差要說清楚

tier-A 90.9% → tier-B 48.9%。落差來自兩個原因,兩個都該講:
1. 超參數(radius=10、K=3)是在 tier-A 上選的,存在選擇性偏差;
2. tier-A 的標註品質較高(條目被沉積者標為 "allosteric"),tier-B 純為幾何代理。

### 3.3 量子讀數在同一框架下輸給古典讀數

我設計了完全相同的「擾動 → 在活性位點讀取」框架,只替換傳播核:

| 讀數 | tier-A sig / AUC | tier-B sig / AUC |
|---|---|---|
| 無限時間相干傳輸(QASC 的觀測量) | 9.1% / 0.475 | — |
| 有限時間窗相干傳輸(`qpr_coherent`) | 9.1% / 0.358 | 5.6% / 0.400 |
| 古典擴散核(`cpr_classical`) | 27.3% / 0.596 | 42.7% / 0.542 |
| **頻譜位移(`ALPS`)** | **90.9% / 0.757** | **48.9% / 0.603** |

**在同一擾動框架下,明確相干的觀測量表現最差。** 推測原因:局部加勁幾乎不改變主導
長時間相干傳輸的本徵值**簡併**結構,故該觀測量對擾動不敏感、雜訊主導;而低階本徵值
本身會被乾淨地推移。

> 這對「量子優勢」的敘事是負面證據,但 ALPS 讀的正是 CTQW Hamiltonian 的低階頻譜
> ——即量子漫步最慢的相干頻率,同時也是 GNM 最慢的振動模態。**同一組數字,兩種讀法**。
> 本研究不宣稱量子優勢。

### 3.4 頻譜量的消融:哪一個觀測量真的帶訊號

既然頻譜讀數勝出,那是**哪一種**頻譜量?固定圖、擾動與距離校正,只換讀數
(`scripts/ablate_readouts.py`,tier-A,一律 K=3 個模態):

| 讀數 | sig | 中位 p | AUC | hit5 |
|---|---|---|---|---|
| **`dlam` —— 本徵值位移(ALPS)** | **90.9%** | **0.0003** | **0.757** | **36.4%** |
| `dpart` —— anchor 在低模態的參與度變化 | 63.6% | 0.0196 | 0.682 | 18.2% |
| `dgap` —— 能階**間距**變化(簡併結構) | 54.5% | 0.0013 | 0.660 | 18.2% |
| `dipr` —— 模態侷域化變化(逆參與比) | 36.4% | 0.0865 | 0.637 | 9.1% |

後三者才是**量子特有**的量:簡併結構與本徵向量內容——若訊號真由干涉承載,
應該由它們帶。結果單純的本徵值大小全部贏過。

### 3.5 量子漫步可以夾在哪、不能夾在哪

到目前為止已實測五個插入點,**全部失敗**:

| 插入點 | 結果 |
|---|---|
| 絕對 CTQW 傳輸振幅當分數(QASC 的設計) | 失敗——分數與距 anchor 距離相關 −0.60~−0.71,本質是近度排序器 |
| 擾動框架內以相干傳輸為讀數 | 9.1% vs 頻譜讀數 90.9% |
| ENAQT 去相干輔助傳輸 | γ 從 0 掃到 3·J_max 且已校準到跳躍尺度,**未出現最佳點**,全程接近隨機 |
| 擾動下的簡併結構(能階間距) | 54.5% vs 本徵值位移 90.9% |
| 本徵向量內容(anchor 參與度、模態 IPR) | 63.6%、36.4% |

模式一致:**凡依賴相干傳輸機率或本徵向量結構的觀測量都輸,只有本徵值大小贏。**
合理解讀是殘基接觸圖缺乏產生有意義本徵值簡併所需的對稱性,而干涉效應需要簡併才會出現
——這也正是 CTQW 文獻對長時間傳輸的預測。

**量子已經在裡面的位置**:ALPS 讀的 λ_k 就是 CTQW Hamiltonian 的本徵值,即漫步最慢的
相干頻率。但同一組數字也是 GNM 的振動模態,所以這是**框架**不是**優勢**。

**真正還沒被測、依可行性排序**:

1. **組合選擇而非物理傳播**。單殘基擾動古典就能算;真正的生物問題是協同性——哪 **k 個**
   殘基一起加勁時對活性位點擾動最大?這是 C(N,k),N=300、k=5 約 2×10¹⁰ 種組合,
   每次評估還要一次特徵分解,古典上只能貪婪近似。可直接寫成 QUBO/Ising。
   這把量子放在**確實組合困難**的子問題上,而不是放在古典做得更好的物理讀數上。
2. **對稱多聚體**。本 benchmark 每個目標依建構規則只取單一鏈,而單鏈正是沒有簡併的地方。
   對稱寡聚體才是簡併真實存在、且異位性本身就是對稱破缺的區間。上述負面結果**不能**
   外推到那裡,因為根本沒測。
3. **算法加速而非準確度**。ALPS 需 N 次特徵分解,O(N⁴);用量子相位估計在 walk 算子上
   估計譜位移原則上不需完整對角化。這是規模化主張,也是唯一能在上述所有負面結果下存活的框架。

**不值得再調的**:更多相干讀數變體(換時間尺度、初始態、Hamiltonian 正規化)。
已試五種,落在隨機到 27% 之間,而頻譜讀數是 91%。這個差距不是超參數問題。

### 3.6 協同選擇:這是不是個真的組合難題?

單殘基擾動古典就能算;真正的生物問題是**哪 k 個殘基一起**擾動時對活性位點影響最大。
這是 C(N,k)(N=300、k=5 約 2×10¹⁰),且可寫成 QUBO/Ising——量子退火與 QAOA 的標準輸入形式。
`scripts/cooperative.py` 在提出任何求解器之前,先檢驗這個框架值不值得。

**好消息:目標函數確實非可加且有 frustration**

| | tier-A(n=11) | tier-B 留出(n=89) |
|---|---|---|
| 中位 \|J_ij\| / 平均 h | 0.194 | 0.211 |
| \|J\| > 單體效應 10% 的殘基對 | 68.2% | 69.0% |
| **負耦合比例** | **39.8%** | **39.7%** |
| 貪婪找到窮舉最佳解 | 9% 目標 | 7% 目標 |
| 貪婪相對最佳解的短少 | 3.9% | 8.2% |

約 40% 的耦合為負,即真正的 frustration(讓 Ising 問題困難的結構),且貪婪確實不夠好。
所以 QUBO 框架是合法的,不是硬套。

**壞消息:三個獨立發現關上了量子求解器的門**

**(1) 古典模擬退火已經精確解掉它。**

| 候選數 M | k | C(M,k) | 退火 = 窮舉最佳解 |
|---|---|---|---|
| 26 | 5 | 65,780 | ✓ 全部目標 |
| 34 | 5 | 278,256 | ✓ |
| 40 | 6 | 3,838,380 | ✓ |
| 34 | 7 | **5,379,616** | ✓ |

殘差約 1e-16,純浮點誤差。搜尋端沒有任何空間。而且真正的成本根本不在搜尋——
在於建 `J` 需要 C(N,2) 次特徵分解。**瓶頸是 oracle,不是最佳化器。**

**(2) 把 surrogate 解得越精確,真實答案反而越差。** 二次近似相對真實本徵值目標函數的
誤差為 16.4%(tier-A)與 **37.9%**(tier-B)。在留出集上,窮舉 QUBO 最佳解的真實
f(S) = **0.797**,而貪婪的集合是 **0.843**——精確最佳化 surrogate 讓真實結果變糟。

**(3) QUBO 最佳解在留出集上沒有任何生物價值。** 命中率(tier-B, n=89):

| 選法 | 命中率 |
|---|---|
| top-k 單體分數 | 23.6% |
| QUBO 貪婪解 | 24.7% |
| **QUBO 窮舉最佳解** | **23.6%** |
| 對照:同一候選集隨機 k 子集 | 25.7% |
| 對照:同一候選集最大空間分散 | **36.0%** |

**精確解出的 QUBO 贏不過在同一短名單裡隨機挑。** tier-A(n=11)上 QUBO 看起來有 45.5%,
到 n=89 完全消失——這是 11 個目標的調參集能支撐什麼、不能支撐什麼的直接教訓。

**結論**:形式上成立、問題確實 frustrated,但古典退火飽和了它、surrogate 太失真不值得
精確求解、結果也沒有生物效益。這是量子求解器最後一個有希望的落點,而它沒有站住。

### 3.7 對照組反而找到的改進:把 top-k 分散開

打敗 QUBO 的那個對照本身是個真實且便宜的改進。分數最高的 k 個殘基通常彼此相鄰
(平均間距僅 8.2 Å),五個殘基其實在**描述同一個位點五次**。

`scripts/diversify.py`,留出集 tier-B(n=90):

| 選法 | 命中率 | 平均內部距離 |
|---|---|---|
| top-5 純分數(ALPS 原本) | 24.4% | 8.2 Å |
| 分數 + ≥10 Å 最小間距 | 31.1% | 16.5 Å |
| **分數取 top-26 短名單 + 最大分散** | **35.6%** | 17.9 Å |
| 對照:同一分散規則套用於整個候選池 | **10.0%** | 34.9 Å |
| 對照:整個候選池隨機 5 個 | 17.8% | 22.4 Å |

**兩半都必要。** 完全不用分數、直接在整個池裡挑最分散,只有 10.0%——**比隨機還差**,
因為那只會挑到蛋白質的角落。分數決定**哪 26 個殘基值得考慮**,分散決定**其中哪 5 個不重複**。

留出集 top-5 命中率提升 **1.46 倍**,只需幾行幾何運算,不需要 QUBO 也不需要量子。
已實作為 `alps_select()`。

### 3.8 對稱多聚體:假說,以及它為何失敗

§3.5 預測干涉類觀測量在單鏈上失敗,是因為單鏈沒有本徵值簡併,而干涉需要簡併。
對稱寡聚體是這個前提不同的區間,所以在那裡測。

**前提成立:對稱確實讓簡併增益**

| 結構 | n | 間距<1% |
|---|---|---|
| 單鏈(tier-B) | 90 | 3.6% |
| 多鏈、對稱未確認 | 31 | 3.1% |
| **確認對稱寡聚體**(鏈間 RMSD<1Å) | **29** | **6.5%** |

近簡併對大約翻倍。這部分紮實,也正是群論預期的結果:交換兩條相同鏈的置換矩陣與
Kirchhoff 矩陣對易,故本徵向量分裂成對稱/反對稱對,本徵值幾乎相等。

**但結論不成立。消融顯示沒有任何交叉:**

| 讀數 | 對稱寡聚體 (n=29)<br>簡併 6.5% | 對稱未確認 (n=31)<br>簡併 3.1% |
|---|---|---|
| **`dlam` 本徵值位移(ALPS)** | **69.0% / 0.678** | **67.7% / 0.709** |
| `dgap` 能階間距(簡併) | 58.6% / 0.629 | 61.3% / 0.682 |
| `dpart` anchor 參與度 | 58.6% / 0.668 | 71.0% / 0.673 |
| `dipr` 模態侷域化 | 51.7% / 0.624 | 58.1% / 0.653 |

單純的本徵值位移在**兩組都贏**。簡併敏感的讀數在簡併增益處並沒有變好,反而略差
(58.6% vs 61.3%)。近簡併率翻倍,顯然不足以讓干涉在真實、有雜訊的接觸圖上帶訊號。

#### 3.8.1 這是對本文件先前版本的更正

在 n=4 個對稱目標時,`dgap` 以 100% 對 75% 領先 `dlam`,本節曾把它報告為
「唯一一個量子特有觀測量的正面結果」。把 benchmark 從 34 個多聚體擴到 88 個、
對稱組從 4 個增加到 29 個之後,結論反轉。先前的讀法是雜訊。

這是本研究中**第二次**小樣本上的強結果在大樣本上蒸發——協同 QUBO 的命中率也一樣,
n=11 時 45.5%,n=89 時掉到 23.6%,低於自己的亂數對照。兩次都保留記錄而非悄悄刪除,
因為這個失敗模式本身才是重點:**連貫的故事、事先預測的機制、看似單調的趨勢,
都不能替代樣本量。**

**目前計數:七個量子漫步的插入點已被實測,七個全部失敗。** 存活下來的不是準確度主張
——見 §3.5。

## 3.9 策展標註:被迫做出的更正

ALLO benchmark 論文的 Supplementary Table S2 提供 118 個 ASBench 蛋白的**策展異位位點與活性位點殘基**
(位點來自 ASD Release 4.10),開放取用且可經 Europe PMC 取得,即使 ASD/CASBench 官方站已失效。
`scripts/build_dataset_curated.py` 轉成 73 個目標,標註對映幾乎無損。

**全部 73 個策展目標:**

| 方法 | AUC | hit5 | sig | DCC≤4Å |
|---|---|---|---|---|
| **`btb_raw`**(bond-to-bond,無距離校正) | **0.618** | 12.3% | **60.3%** | 0.0% |
| `ctqw_only`(純 CTQW 可通達性) | 0.598 | 4.1% | 54.8% | 1.4% |
| `ALPS_noresid` | 0.598 | 12.3% | 47.9% | 1.4% |
| `corrsite` | 0.595 | 8.2% | 46.6% | 1.4% |
| **`qasc_baseline`**(本 repo 要檢驗的 CTQW 方法) | **0.590** | 5.5% | 56.2% | 0.0% |
| **`ALPS`** | 0.577 | 8.2% | 42.5% | 0.0% |
| `apop` | 0.554 | **13.2%** | 39.6% | 1.9% |
| `btb`(含距離校正) | 0.532 | 9.6% | 39.7% | 1.4% |
| 對照 `ctrl_random` | 0.526 | 4.1% | 11.0% | 0.0% |
| 對照 `ctrl_burial` | 0.514 | 5.5% | 26.0% | 0.0% |
| `prs` | 0.449 | 5.5% | 23.3% | 1.4% |
| 對照 `ctrl_dist` | **0.383** | 2.7% | 20.5% | 0.0% |

### 三個已發布主張是錯的

**ALPS 不是最好的方法**——AUC 排第六。本 repo 曾報告為弱的 `btb_raw` 以 0.618 領先。

**CTQW baseline 不在隨機水準**——0.590、56.2% 顯著率,高於亂數對照(0.526、11.0%)**也高於 ALPS**。
「量子漫步方法等同亂數」是代理標籤的性質,不是方法的性質。

**ALPS 的招牌組件在真標籤下有害**——距離條件 z-score 是設計文件最推崇的一步,
但在策展標籤下**降低**準確度(0.577 有 vs 0.598 無)。bond-to-bond 也一樣(0.532 vs 0.618)。

### 原因,以及事後看來為何可預期

代理標籤**依建構規則**要求異位位點距輔因子位點 ≥8 Å,這給了 `ctrl_dist` 強度,
進而讓「距離校正」看起來必要,而 ALPS 正是在帶著這個校正的代理標籤集上調參的。

真實位點完全不是這樣分布:`ctrl_dist` 崩到 **AUC 0.383,遠低於隨機**——
**真實異位位點傾向比 distal 背景更靠近活性位點**,與我們的建構所編碼的正好相反。
一個帶著「校正不存在的偏差」的方法,是在扛一個包袱。

還有一個 N≤500 子集完全掩蓋掉的尺寸效應:

| 方法 | N≤500 (n=24) | N>500 (n=49) |
|---|---|---|
| `ALPS` | 0.622 | 0.556 |
| `btb_raw` | 0.526 | **0.661** |
| `qasc_baseline` | 0.448 | **0.657** |

ALPS 在小結構上最好、大結構上中段;CTQW baseline 相反。
先前版本報告 N≤500 子集,**正好選中了自家方法看起來最好的區間**。

### 最重要的發現:沒有東西贏得過「近度」

`ctrl_dist` 低於隨機,代表它的鏡像高於隨機。把鏡像加進來當對照
——`ctrl_closeness = −距離`,一行、不用圖、不用模型:

| | AUC | 顯著率 |
|---|---|---|
| `btb_raw`(全場最佳方法) | 0.618 | 60.3% |
| **`ctrl_closeness`(−距離)** | **0.617** | **56.2%** |
| `ctqw_only` | 0.598 | 54.8% |
| `ALPS` | 0.577 | 42.5% |

**本 repo 沒有任何方法贏過它。** 最佳方法只領先 0.001 AUC,其餘全部低於一行幾何基準。

這也解釋了量子讀數為何看起來還可以:CTQW 分數與距 anchor 距離相關 **−0.647**。
它就是個近度排序器,而在策展標籤下近度正是預測異位位點的東西。
**0.598 不是量子訊號的證據,是它部分重現了 −距離的證據。**

協議註記:87% 的策展異位殘基落在 distal(≥8 Å)候選池內(中位 100%,只有 1 個目標完全沒有),
所以這不是候選池定義造成的假象。真實位點確實在我們的門檻外**且**比 distal 背景更靠近活性位點,
而預測它們的是後者。

**對後續工作的意涵**:新方法要跨過的門檻不是已發表的最佳分數,而是**一行幾何的 0.617**;
任何新觀測量該問的是「**在對距離做條件後還剩什麼**」。就本文證據,十二個方法沒有一個剩下東西。

### 對距離做條件之後,真正帶訊號的是什麼

原始 AUC 在兩個方向都被混淆(代理標籤被距離、策展標籤被近度),所以無法回答
「這個方法到底懂不懂異位性」。`scripts/partial_auc.py` 用非參數方式移除混淆:
只比較兩者**距活性位點差距 ≤ 2 Å** 的正負例配對,配對內距離資訊已耗盡,
高於機率的部分就是方法帶的額外資訊。

**先驗證指標本身**:`ctrl_closeness` 從 AUC 0.617 塌到 **0.480**,如預期——距離資訊確實被扣除了。
`ctrl_random` 落在 **0.523** 而非 0.500(空間平滑加上正例群聚造成的小偏差),
所以**該對照的地板是 0.523,不是 0.5**。

*雙面板:左為「已知有位點的蛋白質內部,能否把位點排前面」(96 個策展目標,距離配對);
右為「這個蛋白質到底有沒有位點」(55 正 vs 90 負,尺寸配對)。長條自機率線畫起。
**ALPS 贏了左邊、輸了右邊——右邊沒有任何方法贏過 0.57,而純距離對照達 0.752,
表示負例集在幾何上仍與正例不同,該比較尚未乾淨受控。***

全部 72 個策展目標,每個中位 576 組配對:

| 方法 | 分層 AUC | 相對亂數地板 |
|---|---|---|
| **`ALPS_noresid`** | **0.579** | **+0.056** |
| **`ALPS`** | **0.578** | **+0.055** |
| `apop` | 0.541 | +0.018 |
| `corrsite` | 0.526 | +0.003 |
| 對照 `ctrl_random` | 0.523 | — |
| 對照 `ctrl_dist` | 0.521 | −0.002 |
| `btb` | 0.518 | −0.005 |
| `ctqw_only` | 0.515 | −0.008 |
| `btb_raw` | 0.510 | −0.013 |
| `qasc_baseline` | 0.502 | −0.021 |
| 對照 `ctrl_burial` | 0.497 | −0.026 |
| 對照 `ctrl_closeness` | 0.480 | −0.043 |
| **`qfi`(量子 Fisher 資訊)** | **0.464** | **−0.059** |
| `prs` | 0.455 | −0.068 |

**這把 §3.9 的混亂在兩個方向上都解開了:**

- **ALPS 是唯一明確帶有近度以外資訊的方法**(+0.055,其餘全在 ±0.02 內)。
  它在原始 AUC 上排第六是混淆造成的,不是方法本身。
- **`btb_raw` 的第一名來自近度**——原始 AUC 0.618,分層後 0.510,低於亂數地板。
- **量子讀數帶的近度以外資訊基本為零**:`qasc_baseline` 0.502、`ctqw_only` 0.515、`qfi` 0.464,
  都在地板上下。**原本「CTQW 不帶額外資訊」的結論恢復了**,而且現在建立在
  策展標籤與無混淆指標上,而不是代理標籤製造出來的假象上。
- 距離 z-score 不是 ALPS 有效的原因:`ALPS` 與 `ALPS_noresid` 在此無法區分(0.578 vs 0.579)。
  它本來是在補償標籤假象,混淆被正確移除後它只是中性。

**量子 Fisher 資訊——最後一個候選,同樣失敗。** 先前我把整個 QFI 方向誤判為
「需要接觸圖沒有的非厄米結構」,那是因為我讀的論文全是例外點感測器。**厄米生成元的 QFI
完全可計算**,而且通過本研究建立的每一道篩選:不需簡併、不需非厄米結構、
不會坍縮成傳輸振幅(它用到本徵值位移讀數所丟棄的本徵向量重疊)、且本身就是擾動響應。
`methods/qfi.py` 以生成元 `G_i(t) = ∫₀ᵗ U(s)† V_i U(s) ds` 的變異數實作,
與精確本徵基底閉式解驗證到 **2.9e-14、相關係數 1.00000000**。

結果是 **0.464**,低於亂數地板也低於近度對照。**紙上動機最強的最後一個量子候選,
一樣沒帶來幾何以外的東西。**

*(一個值得留下的實作教訓:被積函數以最快模態頻率振盪,若把時間視窗設成最慢模態的週期,
Gauss-Legendre 求積會靜默地解析不足——與閉式解差 6%。改用快模態視窗 2π/λ_max 才正確。
**一個量子觀測量可能因為數值原因而失敗,而那看起來會跟物理結論一模一樣。**)*

**容忍窗不是隱藏旋鈕。** 指標只有一個自由參數(2 Å 配對窗),
`scripts/tol_sweep.py` 把它從 0.5 Å 掃到完全不配對(43 個策展目標,N≤700):

| 方法 | 0.5Å | 1Å | 2Å | 3Å | 4Å | 6Å | 不配對 |
|---|---|---|---|---|---|---|---|
| **`ALPS`** | 0.574 | 0.583 | **0.578** | 0.579 | 0.576 | 0.576 | 0.570 |
| `btb_raw` | 0.523 | 0.519 | 0.525 | 0.529 | 0.530 | 0.536 | **0.574** |
| `ctqw_only` | 0.478 | 0.481 | 0.481 | 0.486 | 0.490 | 0.498 | 0.540 |
| `qasc_baseline` | 0.468 | 0.468 | 0.469 | 0.476 | 0.481 | 0.492 | 0.534 |
| `qfi` | 0.456 | 0.456 | 0.460 | 0.469 | 0.475 | 0.493 | 0.553 |
| 診斷 `ctrl_closeness` | 0.489 | 0.489 | 0.494 | 0.503 | 0.510 | 0.523 | **0.573** |
| 對照 `ctrl_random` | 0.527 | 0.529 | 0.527 | 0.524 | 0.523 | 0.525 | 0.521 |
| *中位配對數* | *104* | *209* | *406* | *600* | *754* | *1113* | *2448* |

**窗口有效,而 2 Å 在安全區內**:`ctrl_closeness` 在 1.5 Å 前維持 0.489、2 Å 是 0.494,
從 3 Å 開始洩漏、6 Å 到 0.523、不配對時回到原始 AUC 的 0.573。**3 Å 以內都能控制混淆,
超過 4 Å 指標就悄悄退回原始 AUC。**

**ALPS 完全不依賴這個選擇**:整段掃描落在 0.574–0.583,連 0.5 Å(每目標只剩約 104 組配對)
也一樣。它的結果不是窗口造成的假象。

**被混淆的方法會在掃描中自己現形**:`btb_raw` 隨窗口放寬從 0.52 爬到 0.574,
三個量子讀數從 ~0.46 爬到 0.53–0.55。**它們的原始 AUC 分數確實就是近度**,
掃描把近度一步一步加回去的過程看得一清二楚。

**限制**:0.523 的地板只由單一亂數對照估計,所以小於約 0.03 的差距不該當真
(涵蓋 `apop` 與 `corrsite`)。而且這量的是判別力不是定位——
沒有任何方法在 DCC ≤ 4 Å 上超過 1.9% 這件事不變。

### 仍然成立的

所有方法都贏過亂數對照的顯著率(23–60% vs 11.0%),任務有訊號;
`ctrl_dist` 反向預測(0.383),距離偏差確為我們標籤定義的假象;
沒有任何方法定位成功(最佳 DCC≤4Å 僅 1.9%)。

### 這對量子結論的影響

七到八個失敗的插入點**全部是在代理標籤上測的**,而排序不會在標籤集之間轉移
(`qasc_baseline` 從「等同亂數」變成「高於 ALPS」)。**那些量子消融應在策展標籤上重跑,
才能當作定論。** 解析結果不受影響(單粒子 OTOC 等於傳輸振幅平方的四倍是代數,非厄米需要
接觸圖沒有的結構也是),但**實證排序不成立**。

## 5. 限制(必須與結論一起引用)

1. **標註是幾何代理**:`y` = 「一個類藥物分子結晶於此且距催化位點 ≥ 8 Å」,
   不等於實驗證實的異位調控位點。tier-A 額外要求條目被標註 "allosteric"。
2. **測試集有距離偏差**:`ctrl_dist` 在兩個獨立集都有 46–55% 顯著率。**只有在
   顯著率之外還能贏過它的方法才算有證據**——ALPS 靠的是 hit5,不是 sig。
3. **ALPS 超參數選自 tier-A**,tier-B 才是無偏估計。
4. **座標為 holo 構型**(移除配體後只用蛋白座標),嚴格說不是 apo;QASC 三目標是 apo。
5. **`apop`/`qpr`/`cpr` 在 N>660 的目標上跳過**(O(N) 次特徵分解),故其 n 略少於 57。
6. **小樣本會誤導,而且發生了兩次**:協同 QUBO 在 n=11 時命中率 45.5%,n=89 時
   掉到 23.6%(低於自己的亂數對照);對稱多聚體的讀數結論在 n=4 與 n=29 之間反轉。
   本文件中任何來自小於約 30 個目標的數字,都應視為假說而非結論。
7. 樣本量:tier-A 僅 11。tier-B 90 較穩健,但 48.9% 的 95% CI 約 ±10%,故
   ALPS 對 `ctrl_dist`、對 `apop` 的**顯著率**差距都在區間內;唯有 hit5 的差距
   (24.4% vs 7.8%)明確超出。

## 附錄:任務、資料格式與方法一覽

**任務**:輸入 `(N,3)` 的 Cβ 座標 + 活性位點殘基索引,輸出每殘基分數,再從
「距 anchor ≥8 Å 且非 anchor」的候選池取前五名。主要指標是**距離分層 AUC**
(只比較距離差 ≤2 Å 的正負例配對),因為原始 AUC 在兩種標籤下都被近度主導(§3.9)。

**資料格式**:每個目標一個 `.npz`,欄位一致——
`cb` `(N,3)` Cβ 座標(甘胺酸與缺失處以 Cα 代替)、
`anchor` `(A,)` 活性位點的 0-based 索引、
`y` `(N,)` 異位位點為 1(**僅供評估,方法看不到**)、
`resnums` `(N,)` 作者殘基編號、
`chain_id` `(N,)` 鏈標識(策展/多聚體/配對集才有)。

**八個目標集**,三種標註規則,而**數字出自哪一集會改變它的意義**:

| 目標集 | n | 標註 |
|---|---|---|
| `targets_curated/` | 97 | **專家策展**(ASBench/ASD),頭條結果所用 |
| `targets/` `targets_b/` | 11 / 90 | 幾何代理,**已證實受混淆**(§3.9) |
| `targets_multimer/` | 88 | 幾何代理,整個組裝體 |
| `targets_negative/` | 90 | **無異位位點**的蛋白質層級負例 |
| `matched_pos/` `matched_neg/` | 18 / 83 | 兩類走同一條 pipeline 的修正版 |
| `qasc_targets/` | 3 | 受測方法自附 |

**方法**:`ALPS`(局部加勁後讀最低三個 Kirchhoff 本徵值位移 + 距離 z-score,**唯一過地板**)、
`apop`(同樣加勁,讀全域模態頻率位移,不用 anchor)、`corrsite`(GNM 快慢模態相關性)、
