## 2. QASC 的診斷

### 2.1 它在自己的三個目標上是真的

`qasc_baseline` 在 QASC 自選目標上 100% 顯著、AUC 0.731,而**三個平庸對照全部失敗**
(距離 0%、亂數 0%、埋藏度 33%)。頭條結果不能用「其實只是距離或埋藏度」解釋,應予承認。

### 2.2 但在 68 個獨立目標上等同於亂數

tier-A 9.1%、**tier-B 7.8%,低於亂數對照的 8.9%**;AUC 一致低於 0.5
(0.412 / 0.416)——不是沒訊號,是**系統性把真異位殘基排在背景之下**。
top-5 命中率在 90 個留出目標上是 **4.4%**,亦低於亂數對照的 13.3%。

### 2.3 原因:分數本質上是「離活性位點的近度」

corr(QASC 分數, 距 anchor 距離)在三個集上分別是 **−0.713 / −0.621 / −0.604**
(此量與標註無關,純為 QASC 本身性質)。而它自選的三個目標恰好有個共同性質:
標註的異位殘基比 distal 背景**更靠近**活性位點(平均近 4.2 Å);獨立集上則偏遠
(+1.0 Å / +4.0 Å)。一個「近度排序器」在前者顯著、在後者反向失效,AUC<0.5 由此而來。

## 3. ALPS:本研究提出的新方法

定義與設計依據見 [`README.md`](README.md)。要點:局部加勁擾動 → 讀 Kirchhoff 矩陣
**最低 3 個非零本徵值的相對位移** → 對距離做條件 z-score。

### 3.1 留出集表現

在 90 個未參與調參的目標上:

- **AUC 0.603**,高於 APOP 的 0.564、QASC 的 0.416
- **top-5 命中率 24.4%**,約為距離對照(7.8%)的 **3.1 倍**、APOP(17.2%)的 1.4 倍,
  而 QASC 只有 4.4%
- 顯著率 48.9%,高於距離對照(45.6%),但略低於 APOP(50.6%)
- 強方法中中位 DCC 最短(20.2 Å vs APOP 26.4 Å)

**誠實的解讀**:ALPS 在顯著率上贏過距離對照的幅度很小(48.9% vs 45.6%),落在信賴區間內;
`apop` 的顯著率甚至略高(50.6%),但在 AUC、hit5、DCC 三項都輸。ALPS 真正站得住的優勢是
**定位**——top-5 命中率 24.4% vs 距離對照 7.8%,這個差距才明顯超出誤差範圍。
如果目標是「產出 5 個值得做實驗的候選殘基」,ALPS 是較好的選擇;
如果只問「這個蛋白質有沒有富集訊號」,兩者等價。

拿掉距離 z-score(`ALPS_noresid`)會損失顯著率(46.7%)與 AUC(0.584),但 hit5 不降
(25.6%),表示該校正銳化的是整體排序而非最頂端。

### 3.2 調參集到留出集的落差要說清楚

tier-A 90.9% → tier-B 48.9%。落差來自兩個原因,兩個都該講:
1. 超參數(radius=10、K=3)是在 tier-A 上選的,存在選擇性偏差;
2. tier-A 的標註品質較高(條目被沉積者標為 "allosteric"),tier-B 純為幾何代理。

### 3.3 量子讀數在同一框架下輸給古典讀數

我設計了完全相同的「擾動 → 在活性位點讀取」框架,只替換傳播核:

| 讀數 | tier-A sig / AUC | tier-B sig / AUC |
|---|---|---|
| 無限時間相干傳輸(QASC 的觀測量) | 9.1% / 0.475 | — |
| 有限時間窗相干傳輸(`qpr_coherent`) | 9.1% / 0.358 | 5.6% / 0.400 |
| 古典擴散核(`cpr_classical`) | 27.3% / 0.596 | 42.7% / 0.542 |
| **頻譜位移(`ALPS`)** | **90.9% / 0.757** | **48.9% / 0.603** |

**在同一擾動框架下,明確相干的觀測量表現最差。** 推測原因:局部加勁幾乎不改變主導
長時間相干傳輸的本徵值**簡併**結構,故該觀測量對擾動不敏感、雜訊主導;而低階本徵值
本身會被乾淨地推移。

> 這對「量子優勢」的敘事是負面證據,但 ALPS 讀的正是 CTQW Hamiltonian 的低階頻譜
> ——即量子漫步最慢的相干頻率,同時也是 GNM 最慢的振動模態。**同一組數字,兩種讀法**。
> 本研究不宣稱量子優勢。

### 3.4 頻譜量的消融:哪一個觀測量真的帶訊號

既然頻譜讀數勝出,那是**哪一種**頻譜量?固定圖、擾動與距離校正,只換讀數
(`scripts/ablate_readouts.py`,tier-A,一律 K=3 個模態):

| 讀數 | sig | 中位 p | AUC | hit5 |
|---|---|---|---|---|
| **`dlam` —— 本徵值位移(ALPS)** | **90.9%** | **0.0003** | **0.757** | **36.4%** |
| `dpart` —— anchor 在低模態的參與度變化 | 63.6% | 0.0196 | 0.682 | 18.2% |
| `dgap` —— 能階**間距**變化(簡併結構) | 54.5% | 0.0013 | 0.660 | 18.2% |
| `dipr` —— 模態侷域化變化(逆參與比) | 36.4% | 0.0865 | 0.637 | 9.1% |

後三者才是**量子特有**的量:簡併結構與本徵向量內容——若訊號真由干涉承載,
應該由它們帶。結果單純的本徵值大小全部贏過。

### 3.5 量子漫步可以夾在哪、不能夾在哪

到目前為止已實測五個插入點,**全部失敗**:

| 插入點 | 結果 |
|---|---|
| 絕對 CTQW 傳輸振幅當分數(QASC 的設計) | 失敗——分數與距 anchor 距離相關 −0.60~−0.71,本質是近度排序器 |
| 擾動框架內以相干傳輸為讀數 | 9.1% vs 頻譜讀數 90.9% |
| ENAQT 去相干輔助傳輸 | γ 從 0 掃到 3·J_max 且已校準到跳躍尺度,**未出現最佳點**,全程接近隨機 |
| 擾動下的簡併結構(能階間距) | 54.5% vs 本徵值位移 90.9% |
| 本徵向量內容(anchor 參與度、模態 IPR) | 63.6%、36.4% |

模式一致:**凡依賴相干傳輸機率或本徵向量結構的觀測量都輸,只有本徵值大小贏。**
合理解讀是殘基接觸圖缺乏產生有意義本徵值簡併所需的對稱性,而干涉效應需要簡併才會出現
——這也正是 CTQW 文獻對長時間傳輸的預測。

**量子已經在裡面的位置**:ALPS 讀的 λ_k 就是 CTQW Hamiltonian 的本徵值,即漫步最慢的
相干頻率。但同一組數字也是 GNM 的振動模態,所以這是**框架**不是**優勢**。

**真正還沒被測、依可行性排序**:

1. **組合選擇而非物理傳播**。單殘基擾動古典就能算;真正的生物問題是協同性——哪 **k 個**
   殘基一起加勁時對活性位點擾動最大?這是 C(N,k),N=300、k=5 約 2×10¹⁰ 種組合,
   每次評估還要一次特徵分解,古典上只能貪婪近似。可直接寫成 QUBO/Ising。
   這把量子放在**確實組合困難**的子問題上,而不是放在古典做得更好的物理讀數上。
2. **對稱多聚體**。本 benchmark 每個目標依建構規則只取單一鏈,而單鏈正是沒有簡併的地方。
   對稱寡聚體才是簡併真實存在、且異位性本身就是對稱破缺的區間。上述負面結果**不能**
   外推到那裡,因為根本沒測。
3. **算法加速而非準確度**。ALPS 需 N 次特徵分解,O(N⁴);用量子相位估計在 walk 算子上
   估計譜位移原則上不需完整對角化。這是規模化主張,也是唯一能在上述所有負面結果下存活的框架。

**不值得再調的**:更多相干讀數變體(換時間尺度、初始態、Hamiltonian 正規化)。
已試五種,落在隨機到 27% 之間,而頻譜讀數是 91%。這個差距不是超參數問題。

### 3.6 協同選擇:這是不是個真的組合難題?

單殘基擾動古典就能算;真正的生物問題是**哪 k 個殘基一起**擾動時對活性位點影響最大。
這是 C(N,k)(N=300、k=5 約 2×10¹⁰),且可寫成 QUBO/Ising——量子退火與 QAOA 的標準輸入形式。
`scripts/cooperative.py` 在提出任何求解器之前,先檢驗這個框架值不值得。

**好消息:目標函數確實非可加且有 frustration**

| | tier-A(n=11) | tier-B 留出(n=89) |
|---|---|---|
| 中位 \|J_ij\| / 平均 h | 0.194 | 0.211 |
| \|J\| > 單體效應 10% 的殘基對 | 68.2% | 69.0% |
| **負耦合比例** | **39.8%** | **39.7%** |
| 貪婪找到窮舉最佳解 | 9% 目標 | 7% 目標 |
| 貪婪相對最佳解的短少 | 3.9% | 8.2% |

約 40% 的耦合為負,即真正的 frustration(讓 Ising 問題困難的結構),且貪婪確實不夠好。
所以 QUBO 框架是合法的,不是硬套。

**壞消息:三個獨立發現關上了量子求解器的門**

**(1) 古典模擬退火已經精確解掉它。**

| 候選數 M | k | C(M,k) | 退火 = 窮舉最佳解 |
|---|---|---|---|
| 26 | 5 | 65,780 | ✓ 全部目標 |
| 34 | 5 | 278,256 | ✓ |
| 40 | 6 | 3,838,380 | ✓ |
| 34 | 7 | **5,379,616** | ✓ |

殘差約 1e-16,純浮點誤差。搜尋端沒有任何空間。而且真正的成本根本不在搜尋——
在於建 `J` 需要 C(N,2) 次特徵分解。**瓶頸是 oracle,不是最佳化器。**

**(2) 把 surrogate 解得越精確,真實答案反而越差。** 二次近似相對真實本徵值目標函數的
誤差為 16.4%(tier-A)與 **37.9%**(tier-B)。在留出集上,窮舉 QUBO 最佳解的真實
f(S) = **0.797**,而貪婪的集合是 **0.843**——精確最佳化 surrogate 讓真實結果變糟。

**(3) QUBO 最佳解在留出集上沒有任何生物價值。** 命中率(tier-B, n=89):

| 選法 | 命中率 |
|---|---|
| top-k 單體分數 | 23.6% |
| QUBO 貪婪解 | 24.7% |
| **QUBO 窮舉最佳解** | **23.6%** |
| 對照:同一候選集隨機 k 子集 | 25.7% |
| 對照:同一候選集最大空間分散 | **36.0%** |

**精確解出的 QUBO 贏不過在同一短名單裡隨機挑。** tier-A(n=11)上 QUBO 看起來有 45.5%,
到 n=89 完全消失——這是 11 個目標的調參集能支撐什麼、不能支撐什麼的直接教訓。

**結論**:形式上成立、問題確實 frustrated,但古典退火飽和了它、surrogate 太失真不值得
精確求解、結果也沒有生物效益。這是量子求解器最後一個有希望的落點,而它沒有站住。

### 3.7 對照組反而找到的改進:把 top-k 分散開

打敗 QUBO 的那個對照本身是個真實且便宜的改進。分數最高的 k 個殘基通常彼此相鄰
(平均間距僅 8.2 Å),五個殘基其實在**描述同一個位點五次**。

`scripts/diversify.py`,留出集 tier-B(n=90):

| 選法 | 命中率 | 平均內部距離 |
|---|---|---|
| top-5 純分數(ALPS 原本) | 24.4% | 8.2 Å |
| 分數 + ≥10 Å 最小間距 | 31.1% | 16.5 Å |
| **分數取 top-26 短名單 + 最大分散** | **35.6%** | 17.9 Å |
| 對照:同一分散規則套用於整個候選池 | **10.0%** | 34.9 Å |
| 對照:整個候選池隨機 5 個 | 17.8% | 22.4 Å |

**兩半都必要。** 完全不用分數、直接在整個池裡挑最分散,只有 10.0%——**比隨機還差**,
因為那只會挑到蛋白質的角落。分數決定**哪 26 個殘基值得考慮**,分散決定**其中哪 5 個不重複**。

留出集 top-5 命中率提升 **1.46 倍**,只需幾行幾何運算,不需要 QUBO 也不需要量子。
已實作為 `alps_select()`。

### 3.8 對稱多聚體:唯一一個量子特有觀測量勝出的地方

§3.5 把對稱寡聚體列為最後一個未測區間,理由是:所有依賴干涉的觀測量在單鏈上都失敗,
而單鏈根本沒有本徵值簡併——干涉需要簡併才會出現。現在測了。

**第一步:簡併真的有增益嗎?**(前 20 個非零本徵值中相對間距 < 1% 的比例)

| 結構 | n | 間距<1% | 間距<5% | 中位間距 |
|---|---|---|---|---|
| 單鏈(tier-B) | 90 | 3.6% | 38.7% | 7.0% |
| **確認對稱寡聚體(鏈間 RMSD<1Å)** | 26 | **6.3%** | 44.1% | 5.8% |

近簡併對大約翻倍。幅度不大但真實——而且**如果把對稱與非對稱多鏈混在一起就看不到**,
我第一次分析正是這樣漏掉的。

**第二步:簡併敏感的讀數會在有簡併的地方勝出嗎?**(同一擾動、同一距離校正)

| 讀數 | 單鏈<br>(簡併 3.6%) | 非對稱多鏈<br>(2.0%) | **對稱寡聚體<br>(6.6%)** |
|---|---|---|---|
| `dlam` 本徵值位移(ALPS) | **90.9%** / 0.757 | **50.0%** / 0.665 | 75.0% / 0.635 |
| `dgap` 能階間距(簡併) | 54.5% / 0.660 | 37.5% / 0.631 | **100.0%** / **0.731** |
| `dpart` anchor 參與度 | 63.6% / 0.682 | 62.5% / 0.645 | 50.0% / 0.647 |
| `dipr` 模態侷域化 | 36.4% / 0.637 | 50.0% / 0.660 | 50.0% / 0.636 |

*(格式為 置換顯著率 / 平均 AUC)*

**勝負順序完全跟著簡併程度翻轉**,方向正如假說預測:近簡併稀少時,單純的本徵值位移
大幅勝出;近簡併增益時,讀取簡併結構的觀測量反超,而且在每個目標上都顯著(中位 p=0.0037)。

> **這是本 repo 中唯一一個量子特有觀測量的正面結果,而且是初步的。** 對稱組僅 n=4。
> 訊號是連貫的——三個簡併程度、單調的勝負順序、機制是事先預測而非事後湊出來的——
> 但四個目標撐不起結論。它證成的是「值得建一個有統計檢定力的對稱寡聚體 benchmark」,
> 而不是一個主張。

## 4. 沒有任何方法通過 DCC ≤ 4 Å

所有方法、所有測試集的 DCC ≤ 4 Å 成功率**皆為 0%**,中位 DCC 約 18–33 Å。
富集顯著性與「指對地方」是兩件事;純接觸圖方法在後者上全面不足。
(注意 `ctrl_random` 的中位 DCC 20.5 Å 反而不差,說明 DCC 中位數本身容易被
「預測落在蛋白質中心附近」灌水,**單看 DCC 中位數會誤導,應與 hit5 併看**。)

## 5. 限制(必須與結論一起引用)

1. **標註是幾何代理**:`y` = 「一個類藥物分子結晶於此且距催化位點 ≥ 8 Å」,
   不等於實驗證實的異位調控位點。tier-A 額外要求條目被標註 "allosteric"。
2. **測試集有距離偏差**:`ctrl_dist` 在兩個獨立集都有 46–55% 顯著率。**只有在
   顯著率之外還能贏過它的方法才算有證據**——ALPS 靠的是 hit5,不是 sig。
3. **ALPS 超參數選自 tier-A**,tier-B 才是無偏估計。
4. **座標為 holo 構型**(移除配體後只用蛋白座標),嚴格說不是 apo;QASC 三目標是 apo。
5. **`apop`/`qpr`/`cpr` 在 N>660 的目標上跳過**(O(N) 次特徵分解),故其 n 略少於 57。
6. **11 個目標的調參集會誤導**:協同 QUBO 在 tier-A 上看起來很強(命中率 45.5%),
   到 tier-B 完全消失(23.6%,低於隨機對照)。所有 tier-A 數字都應視為假說而非結論。
7. 樣本量:tier-A 僅 11。tier-B 90 較穩健,但 48.9% 的 95% CI 約 ±10%,故
   ALPS 對 `ctrl_dist`、對 `apop` 的**顯著率**差距都在區間內;唯有 hit5 的差距
   (24.4% vs 7.8%)明確超出。
